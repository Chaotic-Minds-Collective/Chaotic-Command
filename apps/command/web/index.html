AI-assisted design

    
Chaotic Command does not connect to an AI provider. Describe your server or requested changes, copy the prompt into ChatGPT or another AI assistant, then paste its JSON response here. When your editor already contains a structure, the prompt includes it as a starting draft for refinement. Nothing is sent to an AI service automatically.

Review and edit the structure

  
Enter one role name per line. Existing exact matches will be reused without changing permissions. New roles receive zero permissions and are not assigned.

  
  
  
Enter one category per line using Category name | channel-one, channel-two. Channel names must use lowercase letters, numbers, hyphens, or underscores.

  
  
  
Custom plans are limited to 20 roles, 20 categories, 30 channels per category, and 100 total objects. No Discord changes happen while editing.




Setup is additive: no objects are deleted, no existing permissions are changed, and new roles have zero permissions. New channels inherit category/server permissions and may be public. Existing roles are reused as-is. Review your Discord permissions before applying.
